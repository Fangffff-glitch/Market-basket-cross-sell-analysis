# Data

Raw datasets are not included in this repository because they are large and were provided for academic use.

To run the notebook locally, add the dunnhumby Complete Journey CSV files to:

```text
data/csv/
```

Core expected files:

- `transaction_data.csv`
- `product.csv`
- `causal_data.csv`

Optional files for extended analysis:

- `hh_demographic.csv`
- `campaign_desc.csv`
- `campaign_table.csv`
- `coupon.csv`
- `coupon_redempt.csv`

The `data/csv/` folder is intentionally ignored by Git so raw data stays local and is not uploaded to GitHub.
